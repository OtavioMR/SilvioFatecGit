# Olá, Professor!

Página estática criada para praticar Git. A saudação muda de acordo com o horário local e a página inclui um estilo responsivo com animação sutil.

## Executar localmente

Abra um terminal nesta pasta e execute:

```powershell
python -m http.server 8765
```

Depois acesse <http://127.0.0.1:8765/>.
